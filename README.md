# Rueda Libre

Sitio web de alquiler de bicicletas, tarifas, rutas y reservas en Medellín.

## Contenido

- `index.html`: página principal con servicios, promociones y bicicletas.
- `paginas/`: páginas de tarifas y reservas.
- `pruebas/`: catálogo de bicicletas hecho con Bootstrap.
- `css/`: estilos propios del sitio.
- `img/`: imágenes y logos.
- `bitacora.txt`: apuntes del proyecto.

## Ramas

- `main`: versión con CSS propio, sin Bootstrap.
- `bootstrap`: versión que usa Bootstrap y CSS propio.

Abre `index.html` para ver el sitio.
